# 📚 Student Learning Resource Portal

A web-based Student Learning Resource Portal developed using **Python**, **Django**, **HTML**, **CSS**, **Bootstrap**, and **JavaScript**. This platform enables students to access, upload, and download study materials while allowing administrators to efficiently manage educational resources.

---

## 🎯 Project Objective

The Student Learning Resource Portal is designed to provide a centralized platform where students can easily access learning resources anytime and anywhere. It supports digital learning by organizing educational materials in one place.

This project is developed as part of the **Sustainable Development Goal (SDG) 4 – Quality Education**.

## 🚀 Installation

### Clone the Repository

```bash
git clone https://github.com/AnakhaG/student-learning-resource-portal.git
```

### Navigate to the Project

```bash
cd student-learning-resource-portal
```

### Create a Virtual Environment

```bash
python -m venv venv
```

### Activate Virtual Environment

**Windows**

```bash
venv\Scripts\activate
```

**Linux / macOS**

```bash
source venv/bin/activate
```

### Install Dependencies

```bash
pip install -r requirements.txt
```

### Apply Migrations

```bash
python manage.py migrate
```

### Run the Development Server

```bash
python manage.py runserver
```

Open your browser and visit:

```
http://127.0.0.1:8000/
```
